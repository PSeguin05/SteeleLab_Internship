# SteeleLab Internship

Public repository containing the work completed during my internship at **SteeleLab**, **TU Delft**.

## Public scripts

Most of the scripts I developed during my internship for measurements and data analysis are publicly available in this repository.

The `tunable_microwave_cavity` package is a Python library that I developed myself during the internship, so it is fully open-source and included here.

## Private code

Some of my work depends on internal SteeleLab packages and infrastructure. Since I am unsure whether I have permission to redistribute that code, those scripts are not included in this repository.

Only the parts that are independent of SteeleLab's proprietary software have been made public.
